## 2. Structured Excel Reports

### 2.1 VSAM Step 03: Type Gate Report
* **Path:** `vsam/reports/03_type_gate_report.xlsx`
* **Layout (11 Columns):**

| Column | Description | Example |
| :--- | :--- | :--- |
| `s3 filename` | Discovered S3 file basename | `FDICSWP_FDIC_VSAMKORG_FLAT_20260901.csv.gz` |
| `tablename` | Target destination table | `vsamkorg` |
| `copybook` | Mapped copybook name | `VSAMKORG.txt` *(or `NO_COPYBOOK`)* |
| `korg column` | Detected or mapped schema column | `korg` *(or `NO_KORG`)* |
| `rows checked` | Evaluated non-sentinel rows | `1000` |
| `pk status` | Uniqueness test outcome | `UNIQUE_VALID`, `DUPLICATES_DETECTED`, `NO_PK` |
| `pk columns` | Candidate PK column list | `korg, account_id` |
| `schema_col_is_pk` | Relationship of schema col to PK | `COMPOSITE_PK_PART`, `SOLE_PK`, `NOT_IN_PK` |
| `gate verdict` | Quality gate evaluation | `PASS`, `FAIL`, `EMPTY_NO_DATA` |
| `type errors` | Detected type discrepancies | `None` *(or discrepancy details)* |
| `full s3 uri` | Full S3 URI path | `s3://migration-bucket/vsam/FDICSWP_...` |

### 2.2 VSAM Step 06: Ingestion Load Report
* **Path:** `vsam/reports/load_data_report_<timestamp>.xlsx`
* **Sheets:** `LoadSummary` (Master File Execution) and `SchemaBreakdown` (Cross-Tabulation Matrix).

#### Sheet 1: `LoadSummary` (17 Columns)
1. `s3 filename`: Source S3 file basename.
2. `tablename`: Target PostgreSQL table.
3. `copybook`: Copybook name or `NO_COPYBOOK` if unmapped.
4. `korg column`: Mapped schema segregation column or `NO_KORG`.
5. `total recs`: Total raw records present in source file.
6. `loaded recs`: Total records successfully inserted/upserted.
7. `skipped recs`: Records skipped due to PK violations or duplicate keys.
8. `records loaded in mapped schema`: Records routed to explicitly mapped destination schemas.
9. `records loaded in unmapped schema`: Records routed to non-mapped existing schemas.
10. `records loaded in bcs schema`: Records routed to the fallback `bcs` schema.
11. `load %`: Percentage of records loaded into mapped schema: `(mapped_loaded / total_records) * 100`.
12. `has PK?`: `YES` if table has deployed PK constraint; else `NO`.
13. `PK columns`: Primary key column names used for upsert.
14. `skipped/failed reason`: Exact error message or reason for skipping.
15. `duration`: File streaming and load duration in seconds.
16. `status`: `SUCCESS`, `SKIPPED`, or `FAILED`.
17. `full s3 uri`: Complete S3 object URI.

#### Sheet 2: `SchemaBreakdown` (Pivot Matrix)
Cross-tabulates rows against schemas:
- **Rows:** `s3 filename` and `tablename`.
- **Columns:** Dynamic destination schemas (`bcs`, `bss01104`, `bss01105`, `bss01112`, etc.) + `Total` column.
- **Intersections:** Total records committed to that specific schema for that file.
- **Summary:** Bottom `TOTAL` row consolidating all schema commits.

### 2.3 VSAM Step 07 & Oracle Step 08: Validation Reports
* **Oracle:** `oracle/reports/08_validate_report_<timestamp>.xlsx` (10 tabs)
* **VSAM:** `vsam/reports/07_validate_report_<timestamp>.xlsx` (5 tabs)

Includes side-by-side reconciliation of:
- `Executive_Summary`: High-level counts, pass/fail status, and audit KPIs.
- `Schema_Comparison`: Schema object parity.
- `Table_Comparison`: Table presence, partition hierarchies.
- `Column_Comparison`: Column datatypes, lengths, precision, nullability.
- `Row_Count_Audit`: Exact `COUNT(*)` vs `sweep_ctl.load_log` vs Oracle catalog metadata.

## 3. PostgreSQL Audit Tables (`sweep_ctl.load_log`)

All streamed file loads are atomically logged to `sweep_ctl.load_log` in the target Aurora PostgreSQL database:

```sql
CREATE TABLE sweep_ctl.load_log (
    load_id         BIGSERIAL PRIMARY KEY,
    track           VARCHAR(30) NOT NULL,          -- 'oracle' or 'vsam'
    schema_name     VARCHAR(128) NOT NULL,
    table_name      VARCHAR(128) NOT NULL,
    s3_uri          TEXT NOT NULL,
    rows_loaded     BIGINT NOT NULL DEFAULT 0,
    rows_skipped    BIGINT NOT NULL DEFAULT 0,
    bytes_loaded    BIGINT NOT NULL DEFAULT 0,
    status          VARCHAR(30) NOT NULL,          -- 'SUCCESS', 'FAILED', 'SKIPPED'
    mode            VARCHAR(30),                   -- 'default' or 'data'
    has_pk          BOOLEAN DEFAULT FALSE,
    pk_columns      TEXT,
    error_message   TEXT,
    started_at      TIMESTAMPTZ NOT NULL,
    completed_at    TIMESTAMPTZ NOT NULL,
    duration_sec    NUMERIC(10,2)
);
```
